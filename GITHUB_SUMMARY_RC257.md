## WAFD ONE 10.0.0 RC257 — Quotation Meal-Count Heading

RC257 corrects the quotation item-table heading in both preview and PDF. The ambiguous Arabic label `يومي` is replaced with the accurate label `عدد الوجبات`, while all RC256 quotation features—including menu-image upload and its appended PDF page—remain unchanged. An idempotent migration refreshes the installed print format during deployment.
