## WAFD ONE 10.0.0 RC260 — Compact Undertaking Layout

RC260 removes the excessive blank space between the undertaking opening paragraph and its details table. The table, terms, signatory, signature and stamp are lifted together by 75 canvas units, preserving their relative alignment. This release changes layout coordinates only and does not alter any undertaking text, fields, permissions, workflows or other system behavior. Layouts with noncanonical spacing coordinates are left untouched, and all RC259 fixes remain included.
