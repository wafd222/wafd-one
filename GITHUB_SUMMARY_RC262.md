## WAFD ONE 10.0.0 RC262 — Approved Undertaking Layout Restore

RC262 restores the undertaking layout used before the RC260/RC261 spacing changes, including the approved positions and dimensions of the table, terms, signature and stamp. It also removes the duplicate global floating back button from the undertaking preview while preserving the original upper-left back button. No undertaking text, permissions, workflows or unrelated system behavior are changed.
