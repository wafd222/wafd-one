## WAFD ONE 10.0.0 RC271 — Simple Delivery Supervisor

This release replaces the Delivery Supervisor's duplicated technical cards with a simple delivery workflow.

### What changed

- Add hotels, mosques, Haram/Iftar sites, companies, and other delivery locations.
- Create a delivery by selecting destination, date, meal, editable delivery time, driver, and optional vehicle/meal count.
- Default delivery times: Breakfast 04:00, Lunch 10:00, Dinner 17:00, Iftar Saim 12:00.
- Send the task directly to the selected driver's multilingual trip screen.
- Driver accepts the task, opens the map, records arrival, and uploads a required delivery photo.
- Require and save actual delivery time and phone GPS coordinates with the proof.
- Show the delivery photo, time, destination, and actual map location in supervisor/management records.
- Keep the existing loading-based delivery workflow unchanged.
- Translate the new driver workflow and meal names in all ten supported employee languages.

### After installation

1. Migrate Site
2. Clear Cache
3. Build Assets
4. Sign out and sign in again
