## WAFD ONE 10.0.0 RC272 — Unified Android and iPhone Home

This release makes the Android employee screen match the approved iPhone experience.

### What changed

- Enable the WAFD mobile shell in Android Chrome and installed Android/iPhone PWAs.
- Show the WAFD menu with the global language selector on Android.
- Hide Frappe's standard navbar, workspace sidebar, notifications, and unrelated workspace links on the role home.
- Display only the practical cards assigned to the employee's WAFD role(s).
- Detect Android/iPhone and touch devices reliably, including wider or desktop-mode mobile viewports.
- Keep desktop management routing unchanged.

### After installation

1. Migrate Site
2. Clear Cache
3. Build Assets
4. Sign out and sign in again
5. Close old Android browser tabs and reopen WAFD ONE
