RC298 — Role-based Iftar workforce operations

- Added dedicated Iftar screens for management/project manager, kitchen supervisor, delivery supervisor, site manager, and field supervisors.
- Added permanent Ramadan/team assignments so supervisors, table owners, assistants, and core managers are registered once and reused daily.
- Added fasting-season scheduling for Ramadan, Monday/Thursday, White Days, the first ten of Dhul Hijjah, Arafah, Ashura, and special projects; Monday/Thursday ranges generate only their actual service days.
- Added one secure daily report per supervisor with table-owner locations, assistant attendance, meal quantities, cartons, operating supplies, closeout, surplus, food-preservation handover, photos, submission, and site-manager approval.
- Added automatic daily supervisor report generation from the permanent project roster, supporting 20+ supervisors without duplicate data entry.
- Added kitchen readiness and material-shortage reporting with approved ready quantities.
- Kept the existing meal delivery schedule as the only driver workflow; no duplicate Iftar trip is created. Driver, vehicle, destination, quantity, timing, receiver, proof photo, and verified arrival quantity now synchronize automatically into the linked Iftar day.
- Corrected the operational sequence to: kitchen readiness, current driver schedule and arrival proof, site-manager receipt, authority food inspection, supervisor handover, field reports, then consolidated official report.
- Added a separate site-manager receipt approval with confirmed quantity, approver and timestamp between driver arrival proof and authority inspection.
- Added 25-meal carton calculations and site-manager handover of tablecloths, bread bags, waste bags, gloves, and shoe covers per supervisor.
- Added consolidated official daily reporting from approved supervisor reports and copied approved field photos into the authority report.
- Added least-privilege row security so each field supervisor sees only their assigned plan and reports.
- Blocked draft Iftar projects from active counts and all operational approvals until project submission.
- Made authority inspection checkboxes empty by default and required inspection photo evidence.
- Required complete driver/vehicle delivery scheduling before delivery approval.
- Reduced and repositioned the mobile stage button so it no longer covers form fields.
