RC299 — إصلاح فشل Migrate Site بعد RC298

سبب الخطأ:
كانت بيانات DocType باسم WAFD Iftar Supervisor Daily Owner موجودة، لكن ملف Python المطابق لها لم يكن موجودًا داخل الحزمة، لذلك توقف Frappe أثناء مزامنة DocTypes برسالة ModuleNotFoundError.

ما تم إصلاحه:
- إضافة ملف Python الصحيح للـ DocType المفقود.
- إضافة Patch استعادة يعيد تحميل جدول أصحاب السفر اليومي وتقرير المشرف اليومي ويمسح الكاش.
- إضافة فحص تلقائي يمنع إصدار أي حزمة إذا كان أي DocType قياسي بلا ملف Python أو __init__.py.
- الحفاظ على جميع شاشات ووظائف وصلاحيات إفطار الصائم الموجودة في RC298 دون حذف أو تغيير بيانات.

خطوات التحديث على Frappe Cloud:
1) ارفع RC299 بدل RC298.
2) شغّل Migrate Site.
3) بعد نجاح الترحيل شغّل Build Assets ثم Clear Cache.
4) افتح الموقع من جديد واختبر شاشة إفطار الصائم.

مهم:
- لا تعِد رفع RC298.
- لا تحذف DocType ولا تنفذ Restore بسبب هذا الخطأ.
- هذا الإصدار مصمم لإكمال الترحيل المتوقف بأمان.
