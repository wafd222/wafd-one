## WAFD ONE 10.0.0 RC345 — إدارة موظفي إفطار الصائم من مكان واحد

### ما تم
- أصبحت شاشة **إدارة الموظفين** هي المكان الوحيد المرئي لإنشاء الحسابات، تحديد المهمات، وإسناد الفريق الأساسي لمشاريع إفطار الصائم.
- أُخفيت حقول اختيار الفريق من نموذج المشروع لمنع التكرار.
- لا تمنح شاشة المشروع أي دور للموظف تلقائياً؛ يجب تحديد مهمته أولاً في إدارة الموظفين.
- مدير المشروع يختار مشرفي السفر فقط من الموظفين الذين يحملون مهمة **مشرف سفر إفطار الصائم**.
- أزيل إعداد المشرفين وأصحاب السفر من شاشة مدير الموقع، وبقي حصرياً لدى مدير المشروع.
- تظهر أسماء مشرفي السفر بوضوح في ملخص المشروع.
- بقيت شاشة مشرف المطبخ مستقلة للإنتاج والتغليف والتحميل وتوزيع السيارات، مع الحفاظ على دخول الحسابات متعددة المهمات لكل شاشة مسندة.

### سير العمل
الإدارة → إدارة الموظفين → مدير المشروع → مشرف المطبخ → جدول السائقين الحالي → مدير الموقع → مشرفو السفر → مدير الموقع → مدير المشروع/الإدارة → الرئاسة.

### العزل والحماية
- لا تغيير على التعهدات أو التوقيعات أو الأختام.
- لا تغيير على Delivery Management أو الرحلات العامة أو بوابة السائق العامة.
- لا تغيير على Offline أو عروض الأسعار أو المخزون أو المالية أو النظافة.
- لا يتم إنشاء رحلة إفطار مستقلة مكررة؛ يستمر استخدام جدول التوصيل الحالي.

### التحقق
- نجحت جميع اختبارات إفطار الصائم RC331–RC345.
- نجح اختبار رحلة السائق والمزامنة RC337.
- نجح اختبار التعهد والتوقيع والقائمة الجانبية RC343.
- نجح فحص صياغة Python وJavaScript وJSON.
