# WAFD ONE 10.0.0 RC103

- Corrected the Iftar project naming series to `WAFD-IFTAR-00001` format.
- Changed project selection to an official site/project list.
- Auto-fills the official contracting authority for the Prophet's Mosque, Quba, Qiblatain and Miqat.
- Added contracting entity type for government entity, establishment, company, association, beneficiary, benefactor or other.
- Automatically loads the standard Iftar meal components on a new project.
- Automatically resolves UOM, latest inventory/market cost, price source and cost per meal.
- Keeps actual ingredient pricing in the ingredient master; no existing operational price is overwritten.
- Preserves all previous hotel/company workflows and existing records.
