# WAFD ONE 10.0.0 RC126

Focused correction release for the Iftar wizard and report center.

- Fixed multi-selection add-on pricing so every selected optional item is included in the automatic sale price.
- Corrected Zamzam pricing as a replacement for standard 330ml water: only the cost difference is added to the 9 SAR base meal.

- Fixed Report Center secondary actions that produced invalid `/advanced_tab` document routes.
- Report cards now open the exact mapped Print Format PDF directly, preventing format leakage/mismatched document buttons.
- Preserved the approved print templates without modifying their layout.
