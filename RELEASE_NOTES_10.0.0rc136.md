# WAFD ONE 10.0.0rc136

## Iftar field operations finalization
- Added approved Prophet's Mosque/Haram distribution-zone master data from the supplied authority allocation table (20 zones, company, location, code).
- Added zone selection to the Iftar project wizard when Prophet's Mosque is selected; the chosen approved location becomes the project distribution site while the contracting authority remains unchanged.
- Added reusable Supervisor Plan records. Each supervisor has a dedicated plan/document containing supervisor contact, assigned meal total, table owners with contacts/locations/meal quantities, and an open-ended assistants list with mobile numbers.
- Added supervisor-plan reuse when copying the previous setup for the same site, so Ramadan/monthly data is entered once and only yearly/project changes need editing.
- Added a dedicated print format: WAFD Iftar Supervisor Team Plan.
- Updated report center and project/daily-operation navigation to surface supervisor/team plans.
- Included the standard Iftar meal packaging (`غلاف إفطار صائم`) in meal material costing for all standard meals while preserving the fixed base sale price of SAR 9.00. The separate WAFD branded outer wrap remains external-distribution only.
- Official authority daily report now clearly labels incomplete reports as Draft and only presents completed execution language when core daily stages and authority food inspection are complete.
- Rebalanced custom Iftar pages from dominant black to a formal Executive Gray / warm-white / muted-gold palette for better mobile readability.
- Corrected site authority defaults for Quba, Qiblatain and Miqat to Madinah Development Authority, while Prophet's Mosque remains under the General Authority for the Care of the Two Holy Mosques.
