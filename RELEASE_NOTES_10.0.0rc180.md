# WAFD ONE 10.0.0 RC180

## Mobile launch and layout correction
- Fixed the legacy `/wafd-mobile` route so existing installed shortcuts no longer open a Page Not Found screen.
- Changed the PWA start route to `/desk/wafd-role-home` so WAFD ONE opens directly on the approved role-aware home after authentication.
- Kept role-aware access and permissions unchanged.
- Polished the mobile “System Sections” cards: equalized card sizing, spacing, icon placement, title wrapping, and description layout.
- Improved long Arabic labels such as Inventory & Purchasing and Master Data without changing the approved visual identity.
