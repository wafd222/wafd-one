# WAFD ONE 10.0.0 RC185

## Scope
Final mobile polish and static permission QA only. The approved operational workflow, print designs, DocTypes, and business data are unchanged.

## Changes
- Added a small safe inset for the WAFD logo on mobile so it is visually separated from the right edge while remaining fully visible.
- Hid the page-level mobile scrollbars for the WAFD role home to remove the thin vertical scroll indicator without disabling scrolling.
- Added a scoped page class so the scrollbar fix does not affect other WAFD ONE pages.
- Added static role/security validation for the current role-home architecture, driver row-level security, and cleaning-store restrictions.
- Version metadata aligned to 10.0.0rc185.

## Migration
No migration patch is required. RC185 does not change DocTypes or operational data.
