# WAFD ONE 10.0.0 RC198 — Undertaking Officer Full Own-Document Actions

- Undertaking Officers can create, edit, save, submit/approve, print, email/send, export/download, share, cancel, amend and delete their own undertaking records.
- Own-document isolation remains enforced: officers cannot access or manage undertakings created by other officers.
- Signature, stamp, logo, fixed terms, signatory data and template/design controls remain protected by RC196 server-side lockdown.
- Hotel, nationality and saved-beneficiary reference masters remain read/select-only.
- System Manager and WAFD Operations Manager retain full management access to all undertakings.
