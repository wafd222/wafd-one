# WAFD ONE 10.0.0 RC199

## Undertaking Officer — Add New Hotel

- Undertaking Officers can create a new WAFD Hotel when it is not available in the hotel selector.
- New hotels become immediately available for selection in undertakings.
- Undertaking Officers retain Read + Select access to hotels.
- Existing hotel records remain protected: Undertaking Officers cannot edit, delete, export, print, share, or report on hotel master records.
- System Manager and WAFD Operations Manager keep full hotel administration permissions.
- All RC198 undertaking workflow and template-lock protections are preserved.
