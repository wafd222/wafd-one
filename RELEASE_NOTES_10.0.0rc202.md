# WAFD ONE 10.0.0 RC202

## Undertaking unified preview and actions

- Replaced separate Preview / Issue / Save / Share controls with one **Preview Undertaking** entry point.
- Preview now opens in a full-screen in-app panel on mobile.
- Approval/issue, Save PDF and Share PDF are available inside the same preview panel.
- After approval, the exact generated PDF replaces the draft preview in the same panel.
- Save PDF now uses an authenticated attachment response instead of relying on a separate browser path.
- Share PDF continues to use the native iOS share sheet when available.
- No changes to undertaking template, signature, stamp, terms, business data, or role restrictions.
