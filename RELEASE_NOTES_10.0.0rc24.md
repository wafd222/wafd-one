# WAFD ONE 10.0.0rc24

## Guided operational workflow

- Added a prominent primary action to every operational stage.
- Production now guides the user through start, completion, quality inspection, food-safety release, and packaging.
- Packaging guides the user to loading after label verification.
- Loading guides the user to dispatch and delivery-trip creation after vehicle, driver, and loading-photo validation.
- Delivery guides the user through departure, arrival, and delivery proof.
- Accepted delivery proof guides the user to invoice creation.
- Open invoices guide the user to payment registration.
- Draft payments guide the user to confirmation and return to the invoice.
- Technical tools remain available under the Operations menu.
- Removed automatic after-save navigation to prevent unintended transitions and duplicate requests.
