# WAFD ONE 10.0.0 RC243

## Unified field delivery access

- Adds **Field Delivery** to the manager, operations manager and delivery supervisor home screens.
- Uses the same mobile trip, arrival, photo, signature and delivery-proof workflow for managers and drivers.
- Keeps drivers restricted to trips assigned to their linked WAFD Driver records.
- Lets authorized managers review and operate current delivery trips without broad File permissions.
- Replaces the standard Delivery Proof attachment action with a secure camera/upload button.
- Fixes the driver's cached **My Trips** page by refreshing trips every time the page is opened.
- Supports accounts linked to more than one WAFD Driver record without widening access to other drivers.
- Blocks future trip creation when the selected driver is not linked to an enabled user account.
- Preserves all RC239-RC242 loading, timing, language and security fixes.
