# WAFD ONE 10.0.0rc25

## Guided material issue and production start

- The main production action now creates missing material issue documents automatically.
- All linked draft material issues are posted in the same server transaction.
- Production starts immediately after successful stock issue.
- Genuine stock shortages remain a hard blocker with detailed ingredient quantities.
- Existing posted issues are reused safely to prevent duplicate stock deductions.
- The primary button clearly states: Issue Materials & Start Production.
