# WAFD ONE 10.0.0 RC277

## Isolated beneficiary delivery screen

- Hides Frappe's general sidebar, notifications and system-section links on the mobile read-only delivery page.
- Adds the same compact WAFD ONE mobile header used by field employees.
- Restricts the read-only beneficiary menu to language selection and logout only.
- Keeps delivery cards, driver details, timestamps and proof photos strictly read-only.
- Does not change manager, supervisor, driver, cleaning, delivery or Iftar permissions and workflows.
- Includes all RC276 Iftar contract/delivery integration changes.

## Upgrade

Install RC277, run migrate, clear cache and restart. On the phone, close and reopen the page after deployment.
