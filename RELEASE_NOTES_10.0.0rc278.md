# WAFD ONE 10.0.0 RC278

## Direct Android field home and isolated internal screens

- Sends field-only Driver, Cleaning Supervisor and Delivery Viewer accounts directly to the unified WAFD role home.
- Prevents Android users from remaining on Frappe's app launcher, generic workspace or unauthorized Page routes.
- Hides Frappe navigation, notifications, workspaces and the system sidebar inside Driver, Cleaning and read-only Delivery pages.
- Adds the compact WAFD ONE field header to Driver and Cleaning internal pages with language and logout only.
- Restricts the unified home menu for field-only and multi-field accounts to language and logout.
- Keeps manager and operational-role navigation unchanged.
- Includes all RC276 Iftar contract delivery integration and all RC277 read-only viewer isolation changes.

## Upgrade

Install RC278, run migrate, clear cache and restart. On Android, close all old WAFD tabs and reopen the system after deployment.
