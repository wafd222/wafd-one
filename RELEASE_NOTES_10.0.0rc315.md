# WAFD ONE 10.0.0 RC315

## Iftar team assignment role fix

- Management can assign an active System User to an Iftar project without manually pre-adding the stage role.
- The system adds only the required assignment role when it is missing.
- Existing user roles are preserved; no role is removed or replaced.
- Global management accounts are not modified.
- Change is limited to the RC314 Iftar stage portal assignment flow.
- No Delivery Management, driver, trip, offline, Undertaking, Quotation, Inventory, Cleaning, Finance, or language workflow is changed.
