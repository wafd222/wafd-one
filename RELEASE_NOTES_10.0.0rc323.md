# WAFD ONE 10.0.0 RC323

## Iftar Site Manager / Supervisor screen separation

- Added a dedicated `wafd-iftar-site` page for Iftar Site Manager.
- Added a dedicated `wafd-iftar-supervisor` page for Iftar Supervisor / table-service supervisor.
- Site Manager can approve site receipt, authority inspection, create supervisor daily tasks, hand over meals/supplies, approve submitted supervisor reports, and finalize the daily site report.
- Iftar Supervisor can see only reports assigned to their user, confirm table-owner handovers, record assistant attendance, and submit daily closeout with required photos.
- Multi-role users no longer land on the same generic Iftar monitoring screen from both role cards.
- Existing kitchen, delivery supervisor, dedicated Iftar driver, and driver offline flows are preserved.
