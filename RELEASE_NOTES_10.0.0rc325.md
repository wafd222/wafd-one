# WAFD ONE 10.0.0 RC325

## Iftar supervisor setup usability
- Adds a mobile-first quick setup inside the Iftar Site Manager screen for supervisors and table owners.
- Supervisor account, name, mobile, and table-owner allocations are entered in one simple dialog.
- Supports multiple supervisors and multiple table owners per supervisor.
- Automatically grants only the WAFD Iftar Supervisor role to selected active users.
- Requires total table-owner meal allocations to equal the project's daily meals before saving.
- Saves into the existing approved RC144 `WAFD Iftar Supervisor Plan` records, preserving the established reporting/data model.
- If the authority inspection is already approved, the page immediately attempts to generate today's supervisor tasks after saving.
- The Supervisor screen now shows a clear pending card when the supervisor is registered in a plan but today's task has not yet been generated, instead of appearing blank.
- No changes to driver offline, dedicated Iftar driver, Delivery Management, Undertaking, Quotation, Inventory, Finance, or unrelated modules.
