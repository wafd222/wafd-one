# WAFD ONE 10.0.0 RC57

- Fixed permanent contract deletion confirmation to accept the single word `DELETE`.
- Added **Reset Test Data** to remove the linked operational and financial chain while preserving the contract.
- Reset returns the contract to Draft and clears its project link for a clean test rerun.
- Added server-side confirmation validation for both DELETE and RESET.
- Improved destructive-action dialogs, totals, cancel action, success messages, and automatic navigation.
- Cleanup remains restricted to Administrator and System Manager.
