# WAFD ONE 10.0.0 RC65

## Professional command center and guided workflow

- Redesigned the WAFD ONE dashboard as a professional operations command center.
- Added direct dashboard actions for creating and viewing Hotel Undertakings.
- Added quick access to contracts, meal plans, invoices, payments, warehouses, stock movements, production and delivery proofs.
- Expanded the visual workflow from Contract through Payment into ten clearly separated stages.
- Added reliable automatic navigation after activating a contract and creating its project.
- Added guided navigation from quality inspection to CCP food-safety verification and then packaging.
- Improved navigation from packaging to loading, loading to delivery, delivery proof to invoice, invoice to payment, and submitted payment to project summary.
- Made payment reference number mandatory and visible only for non-cash payment methods.
- Preserved all RC64 immediate contract deletion and inventory settlement behavior.
