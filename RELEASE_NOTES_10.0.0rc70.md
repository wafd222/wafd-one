# WAFD ONE 10.0.0 RC70

## Purchased Materials Receipt Shortcut

- Added a prominent **استلام مواد مشتراة** shortcut to the dashboard Quick Access area.
- The shortcut opens a new WAFD Stock Movement already configured as **استلام / Receipt**.
- Posting date, draft status, direct-purchase reference, and an audit note are prefilled.
- Authorized System Managers, WAFD Operations Managers, and WAFD Storekeepers can use the same controlled receipt workflow.
- The user still selects the correct target warehouse or cold room and enters item quantities before posting.

All RC69 invoice and payment-completion fixes are preserved.
