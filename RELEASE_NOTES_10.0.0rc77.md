# WAFD ONE 10.0.0 RC77

## Payment and project closure correction

- Payment submission is no longer blocked when unrelated or remaining project deliveries are incomplete.
- A valid payment is submitted and the linked invoice/project financial balances are refreshed first.
- The project is closed automatically only when delivery, invoicing and collection closure conditions are all satisfied.
- If closure is still pending, the user receives a clear informational message and is routed to the linked invoice.
- Existing overpayment, duplicate-reference and cancelled-invoice protections remain unchanged.
