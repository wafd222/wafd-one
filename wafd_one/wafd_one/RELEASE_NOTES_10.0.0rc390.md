# RC390 — Official Iftar Approval Signatures

- Site manager registers an electronic signature once per assigned Iftar project from the site manager screen.
- On final daily report approval, snapshot the assigned site manager name and project signature. Previously approved reports are not backfilled with invented signatures.
- The official report shows names, not user email IDs, and renders the fixed company signature and stamp from the existing undertaking print settings/template/assets (read-only).
- Administration approval uses the configured official assets, not repeated manual uploads.
- No edits to undertaking DocTypes, layouts, print formats, or company settings.
- Existing external viewer mobile navigation and report actions are retained from RC389.
